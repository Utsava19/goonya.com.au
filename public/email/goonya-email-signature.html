Outlook Web — how to add this signature

  1. Edit your details in the yellow box below first (name, title, email).
  2. Select only the yellow box — click inside it, then press Cmd+A (Mac) or Ctrl+A (Windows).
  3. Copy — Cmd+C / Ctrl+C.
  4. In Outlook Web: click the gear icon → View all Outlook settings.
  5. Go to Mail → Compose and reply → Email signature.
  6. Click in the signature box and paste (Cmd+V / Ctrl+V).
  7. Click Save, then compose a new email to check it.

Do not paste from VS Code, Cursor, or a code block in chat — that pastes raw HTML as text. Open this file in Chrome or Safari, then copy the rendered yellow box.
